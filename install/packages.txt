# dotfiles-Fedora/install/packages.txt
# dnf package names for the modern terminal stack. One per line; # comments ok.
# starship, atuin and yazi are installed by bootstrap.sh instead — keep them OUT
# of here. Two different reasons, so don't collapse them back into one line:
#   starship, yazi — genuinely absent from every current Fedora release; the
#     upstream installer (starship) / cargo (yazi) is the only automatic path.
#   atuin — IS packaged now (F43/F44/F45/rawhide ALL carry 18.12.1; F44 caught up),
#     but 18.12.1 still pre-dates 18.19.0, the exact client
#     core/PORTING-MATRIX.md's atuin²⁰ note validated the daemon config-precedence
#     behavior against. Upstream has moved on too — the installer bootstrap.sh runs
#     now lands 18.21.0 (2026-08-31) — so neither route is 18.19.0 any more and the
#     old "known-good vs unvalidated" split no longer separates them. What still does:
#     the installer's drift is FORWARD of the validation, the RPM's is BACKWARD, so the
#     installer stays. Revisit when Fedora ships ≥ 18.19.0: bootstrap.sh's three atuin
#     blocks are all presence-guarded, so adding the name here is the only edit it
#     would take.

duf            # df   (disk usage/free)

               # tealdeer above, same 2026-10-20 date: kept for F43/F44, cargo fallback
               # covers F45+.
yq             # jq-for-YAML — Fedora's `yq` IS mikefarah's Go build (kislyuk's Python yq is not packaged for Fedora at all)
glow           # markdown viewer
gum            # shell-script UI toolkit (charm)
du-dust        # dust (du) — Fedora's package name; installs the `dust` binary, same as Debian's
# xh, sd, doggo, carapace, sesh, gron, op (1Password CLI): NOT reliably in
# Fedora repos — bootstrap.sh installs them via cargo / go / the 1Password repo.
# Two were dropped by Fedora rather than never packaged: gron was orphaned (last
# shipped F41/42) and sd was retired after F41 (rust-sd's `sd` subpackage, last
# built 1.0.0-4.fc41), so `dnf install gron` / `dnf install sd` both fail on a
# current release — hence the go/cargo fallbacks.
# tealdeer and procs are mid-way down that same road: both went orphan and neither
# was rebuilt for F45 or rawhide (F46) — F45 branched 2026-08-11 and neither source
# package (rust-tealdeer, rust-procs) survives in rawhide, so this is retirement with a
# calendar date, not a transient FTBFS — but both still install on F43/F44. They
# therefore stay ACTIVE in this list (removing them would swap a fast RPM for a slow
# source build on every currently-supported release) and bootstrap.sh carries
# presence-guarded cargo fallbacks for them. The dnf install uses --skip-unavailable,
# so once F45 drops the names the transaction skips them instead of failing.

# ── editor + git workflow ─────────────────────────────────────
neovim           # min:0.12.0 — nvim-treesitter (core/nvim, pinned to `main`) will not
                 # merely prefer 0.12, it will not LOAD below it. dnf resolves `neovim` on
                 # every lane but only CLEARS this floor on three: F44/F45/rawhide ship
                 # 0.12.5; F43 ships 0.11.6 and does NOT. F44 crossed 0.11 → 0.12 inside
                 # the release (the 0.12.5 is in `updates`, not at GA) — F43 stayed on the
                 # 0.11 branch and ends its life there, so there is no dnf fix for it.
                 # This floor and tree-sitter-cli's below are two halves of ONE
                 # requirement; only the tree-sitter half used to be recorded (#192).
                 # The authoritative VALUE is NEOVIM_FLOOR in bootstrap.sh, which WARNS on
                 # a short box rather than pretending to fix it (unlike the tree-sitter
                 # half, there is no cargo crate that ships nvim); test/check-packages.sh
                 # asserts the two agree, so this copy cannot silently drift.
git
git-subtree      # `git subtree` ships as a SEPARATE package on Fedora (architecture needs it)
openssh-clients  # ssh / ssh-keygen / ssh-agent — Workstation has it; minimal/Server may not
# lazygit is NOT in Fedora base repos — bootstrap.sh installs it via COPR (atim/lazygit)

tree-sitter-cli # min:0.26.1 — nvim-treesitter (main branch) compiles parsers locally and

                # before it was machine-readable, which is why nothing checked it (#192).
                # F44/F45/rawhide ship 0.26.11 and clear it; F43 ships 0.25.10 and does NOT.
